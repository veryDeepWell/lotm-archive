# Lord of Mysteries — Interactive Archive

Интерактивный справочник по путям и последовательностям Lord of Mysteries. Главный экран — радиальная схема из **22 лучей**; на каждом луче точки идут от Sequence 9 к Sequence 1. Начиная с выбранной главы **268** добавляется точка Sequence 0.

## Запуск

```bash
python -m http.server 8000
```

Открой http://localhost:8000. Не открывай `index.html` напрямую через `file://`: браузер блокирует загрузку JSON.

## Управление

- Нажатие на точку открывает карточку последовательности.
- Выбор главы доступен прямо в шапке: ползунок для прокрутки и числовое поле для ручного ввода. До главы 267 включительно отображаются 9 точек (9–1), с главы 268 — 10 точек (9–0).
- Переключатель «Без спойлеров» управляет видимостью подробностей и названий. Сведения, для которых в JSON не задан проверенный момент раскрытия, остаются `???`, даже если соответствующее место присутствует в справочном каталоге.
- Вкладка «События» сохраняет хронологию из архива.

## Структура

| Файл | Роль |
|---|---|
| `index.html` | Разметка и модальные окна |
| `styles.css` | Оформление радиальной схемы и карточек |
| `app.js` | Отрисовка, прогресс чтения, обработчики |
| `data/archive.json` | Данные путей, последовательностей, персонажей и событий |

В исходном архиве подробные сведения были только для части последовательностей. Эти записи сохранены; для остальных добавлены узлы каталога, но рецепты и способности не выдумываются. Для записей-заглушек неизвестные названия и сведения показываются как `???`, пока в `data/archive.json` не указан проверенный `revealChapter`. База персонажей и событий остаётся неполной и требует дальнейшего обновления.
